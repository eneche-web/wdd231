About BuildWise

BuildWise is a simple educational guide designed to make construction materials information easier to understand.

Join the Chamber

Why BuildWise?

Construction involves many different materials, and each material has its own purpose, advantage, and limitations. For someone learning about construction, finding this information can sometimes be confusing thus informing this guide.

BuildWise brings basic information about common construction materials together in one place. The goal is to give users a starting point before they make construction decisions or continue with more detailed research.

Who Can Use BuildWise?

  • Students: Learn basic information about common construction materials.
  • Homeowners: Become more familiar with materials used around the home.
  • Anyone interested in construction: Explore the basic differences between common materials

How BuildWise Works

  • Materials are stored in a seperate JSON data file.
  • JavaScript loads the material information dynamically.
  • Users can search for materials without reloading the page.
  • Materials can be filtered by category.
  • Users can save favorite materials using loaclStorage.
  • Additional information is displayed using an accessible dialog window
Educational information:

BuildWise is an educational project and is not intended to replace proffessional engineering, architechtural, quantity surveying, or construction advice. Material selection should consider the actual project, environmental conditions, local building requirements, and professional recommendations.
