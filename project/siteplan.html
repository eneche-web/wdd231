Construction Materials Guide

Site Name

BuildWise

BuildWise is a construction materials guide that provides useful information about common building and construction materials. The name was chosen because the website is intended to help users make informed decisions when learning and selecting materials for construction projects.

The name is short, easy to remember, and it communicates the main purpose of the website, thus helping people become more knowledgeable about construction materials.

Site Purpose

BuildWise will provide a simple and useful online guide to common construction and building materials. Visitors will be able to explore different materials, learn about their common uses, properties, advantages, disadvantages, and other important information.

The website will organize material information into easy-to-read sections and cards. JavaScript will be used to load material information from a JSON file and allow visitors to search, filter, and interact with the information.

Scenarios

Scenario 1

I am planning to build a house. What are some common construction materials i should know and what are they use for.

Scenario 2

I am a student learning about construction. Where can i quickly find information about the properties, advantages, and disadvantages of different building materials?

Scenario 3

I am working on a construction project and want to compare several materials before deciding which one may be suitable for a particular part of the project.

Material Card Information

Each material displayed on the website will provide several useful information so that visitors can understand the material without having to search through a large amount of text.

Material Name

The common name of the construction material.

Category

The general group or type of construction material.

Common Uses

Examples of where the material is commonly used.

Properties

Important characteristics of the material.

Considerations

Important limitation or things to consider before using it.

Dynamic Features

JavaScript will make the website interactive instead of displaying all of the information as static HTML.

  • Materials wil be loaded from a JSON data file using fetch().
  • Users will be able to search for a material by name.
  • Users will be able to filter materials by category.
  • Materia details can be displayed in a dialog/modal window.
  • Users will be able to save favorite materials using localStorage.
  • The navigation menu will respond appropriately on smaller screens.
  • The footer will automatically display the current year and last modification information.

Accessibility

Accessibility will be considered throughout the development of BuildWise. The website will use semantic HTML elements and provide clear navigation and readable content.

  • Semantic HTML5 elements will be used.
  • Images will have meaningful alternative text.
  • Form fields will have associated labels.
  • Color contrast will be considered when choosing text and backgrounds.
  • Interactive elements will be usable with a keyboard.
  • Headings will follow a logical hierarchy.
  • The website will be responsive on different screen sizes.
  • Dialog content will be accessible to keyboard users.

Content Sources

General material information will be researched from reliable construction, engineering, manufacturinf, and educational sources. Images will be properly attributed when attribution is required.

The website is intended as an educational guide. Material information will not be presented as professional structural engineering advice. Users should consult qualified construction professionals when making decisions that affect structural safety.

Project Goals

  • Create a useful construction materials reference website.
  • Make construction information easier for beginners to understand.
  • Demonstrate responsive web design skills.
  • Use JavaScript to create dynamic content.
  • Use JSON data to organize material information.
  • Demonstrate browser storage using localStorage.
  • Follow accessibility and HTML/CSS validation practices.
  • Create a website that works well on mobile and desktop devices.
